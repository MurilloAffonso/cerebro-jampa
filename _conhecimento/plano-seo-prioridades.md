## 3. PRINCÍPIOS DE PRIORIZAÇÃO

### Princípio 1: Impacto × Esforço (Matriz 2×2)

```
Impacto Alto
  ├─ Esforço Baixo → FAZER AGORA (quick wins: GMB, FAQ, 3 blogs)
  └─ Esforço Alto → FAZER DEPOIS (29 passeios, 30 blogs, 7 clusters)

Impacto Baixo
  ├─ Esforço Baixo → MICRO-TAREFAS (entre outros)
  └─ Esforço Alto → EVITAR (GetYourGuide, parcerias complexas)
```

### Princípio 2: ROI = Clientes Gerados ÷ Horas Gastas

```
GMB otimizada: +50 clientes ÷ 4 horas = 12.5 clientes/hora
Blog 1º: +20 clientes ÷ 1.5 horas = 13.3 clientes/hora
Passeio Seixas: +30 clientes ÷ 1 hora = 30 clientes/hora (quando ranqueia)
FAQ: +50 keywords ÷ 3 horas (não direto, mas reduz fricção)
Cluster: +15 clientes ÷ 1 hora = 15 clientes/hora

FOCO: Passeio Seixas, Blog Maré, GMB, FAQ (melhor ROI)
```

### Princípio 3: Velocidade > Perfeição

```
Semana 1: Home "ok" (70%) + Seixas "ok" + GMB "ok"
Resultado: +100 clientes/mês em 1 mês

vs.

Mês 1: Home "perfeita" (100%) + Seixas "perfeita" + GMB "perfeita"
Resultado: +100 clientes/mês em 1 mês, DEPOIS DE ESPERAR 1 MÊS

DECISÃO: Semana 1 (rápido) > Mês 1 (perfeito)
```

### Princípio 4: Canais Prioritários

```
Ranking por % tráfego:
1. Google Maps (GMB): 35-45% → FAZER SEMANA 1
2. Google Orgânico (Site): 30-40% → COMEÇAR SEMANA 1, ESCALAR 6 MESES
3. TripAdvisor: 7-12% → FAZER SEMANA 2-3
4. Instagram: 5-15% (50% influência) → FAZER DIA 1
5. Viator: 5-8% (se ROI > 15%) → INVESTIGAR SEMANA 3
6. Direto: 10-15% → Resultado de 1-5

NUNCA em prioridade: GetYourGuide, Civitatis, Booking Exp (ROI baixo)
```

### Princípio 5: Confiança = Conversão

```
Sem ativos de confiança: 5% conversão
Com Cadastur + 4.9/5: 10-15% conversão
Com + Murillo + preço transparente: 20-25% conversão
Com + TripAdvisor + Instagram prova: 30-40% conversão

DECISÃO: Colocar Cadastur + 4.9/5 + Murillo no topo de TUDO
```

## 9. O QUE NÃO FAZER AGORA

❌ **Evitar completamente:**

1. **GetYourGuide** — penetração baixa em Brasil (não no roadmap)
2. **Civitatis** — menor que Viator (esperar depois)
3. **Booking Experiences** — ROI não claro (ignorar)
4. **Campanha paga no Facebook** — sem dados de conversão ainda (mês 3+)
5. **Viator sem investigação** — comissão 25-30% só compensa se ROI > 15%
6. **Parcerias com hotéis** — complexo, sem dados ainda (mês 3+)

❌ **Evitar tática:**

1. **Perfeccionismo** — Home "ok" semana 1 > Home "perfeita" mês 2
2. **Desconto agressivo** — "30% off" treina cliente a pedir desconto (preço justo mantém)
3. **Urgência falsa** — "ÚLTIMA CHANCE" sem limite real = desconfiança
4. **Email como CTA** — sempre WhatsApp (mais rápido)
5. **Blog genérico** — "visite nossos passeios" < "maré baixa é crítica porque..."
6. **Foto stock** — cliente real > modelo stock
7. **Descrição duplicada** — cada plataforma tem contexto diferente

## 10. RISCOS DE DISPERSÃO

### Risco 1: Tentar Fazer Tudo Ao Mesmo Tempo

❌ ERRADO:
```
Semana 1: 29 passeios + 30 blogs + 7 clusters
Resultado: Burnout + nada de qualidade + abandono
```

✅ CERTO:
```
Semana 1: Home + Seixas + GMB + FAQ
Semana 2: +2 passeios + 3 blogs + 1 cluster
Semana 3: +5 passeios + 3 blogs + 1 cluster
Resultado: Sustentável + qualidade + crescimento constante
```

### Risco 2: Ignorar Analytics

❌ ERRADO:
```
Postar e nunca saber qual reel tira mais views
Blog sem saber qual tema converte
```

✅ CERTO:
```
Dashboard simples (Google Search Console, Analytics, Instagram Insights)
Revisar 1x/semana: qual conteúdo trabalhou?
Dobrar o que funciona, remover o que não funciona
```

### Risco 3: Depender 100% de Uma Plataforma

❌ ERRADO:
```
80% tráfego vem de Google Maps
Se algoritmo muda = tráfego cai 50%
```

✅ CERTO:
```
Diversificar: 35% GMB + 30% site + 20% TripAdvisor + 10% Instagram + 5% direto
Multi-canal obrigatório
```

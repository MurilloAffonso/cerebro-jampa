## Estrutura do ID

```
[CODIGO-PAGINA]-[POSICAO]-[NUMERO]
```

### Códigos de Página

| Código | Página |
|--------|--------|
| `HOME` | Home (`/`) |
| `PAC`  | Pacotes (listagem e slugs) |
| `LSU`  | Litoral Sul (listagem e slugs) |
| `LNO`  | Litoral Norte (listagem e slugs) |
| `PIS`  | Piscinas Naturais (listagem e slugs) |
| `CIT`  | City Tour (listagem e slugs) |
| `INT`  | Interestaduais (listagem e slugs) |
| `ABT`  | Sobre (`/sobre`) |
| `FAQ`  | FAQ (`/faq`) |
| `BLG`  | Blog (futuro) |

### Códigos de Posição

| Código | Posição |
|--------|---------|
| `HERO` | Imagem/vídeo principal grande |
| `CARD` | Thumbnail de card |
| `GAL`  | Imagem de galeria interna |
| `BG`   | Background de seção |
| `PRT`  | Retrato (Murillo, clientes) |
| `DTL`  | Detalhe (close-up, areia, mãos, objetos) |

## Instruções para Implementação

Ao inserir uma foto no site, adicionar o atributo `data-foto-id`:

```html
<img
  src="/images/passeios/seixas/hero-01.webp"
  alt="Piscinas naturais de Seixas em maré baixa, João Pessoa"
  data-foto-id="PIS-SEI-HERO-01"
  loading="lazy"
/>
```

### Formatos aceitos
- **WebP** (preferencial) — para performance
- **JPEG** (fallback) — qualidade 85%
- **SVG** — apenas para placeholders e ícones

### Localização no projeto
```
_site/public/images/
  home/                      # HOME-*
  passeios/
    litoral-sul/             # LSU-*
    litoral-norte/           # LNO-*
    piscinas-naturais/       # PIS-*
    city-tour/               # CIT-*
    interestaduais/          # INT-*
    pacotes/                 # PAC-*
  murillo/                   # HOME-PRT-*
```

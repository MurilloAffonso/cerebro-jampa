# Conhecimento: Fornecedores e Parceiros Operacionais

**Status:** v1.0 — estrutura criada, dados pendentes de preenchimento por Murillo (2026-04-29)
**Fonte:** Estrutura definida pela Análise 2.0 — dados reais a confirmar com Murillo
**Risco:** Sem este arquivo, se Murillo precisar de 7 dias off ninguém sabe quem chamar

---

## Por Que Este Arquivo Existe

Hoje o conhecimento de quem são os parceiros operacionais está na cabeça do Murillo. Se ele adoecer, viajar ou simplesmente esquecer um contato, a operação trava. Este arquivo transfere esse conhecimento para o vault de forma consultável.

**Regra de uso:** Antes de acionar um fornecedor para uma saída específica, consultar este arquivo. Se houver dúvida sobre disponibilidade, Murillo confirma diretamente.

---

## Como Preencher

Para cada fornecedor, Murillo preenche os campos abaixo em uma sessão de 1 hora com Claude Code. Os campos marcados com `[CONFIRMAR]` são os que precisam de resposta de Murillo.

## Como Usar em Emergência

Se Murillo precisar acionar um fornecedor rapidamente:
1. Identificar o passeio na tabela de risco acima
2. Ir para a seção do fornecedor correspondente
3. Acionar o contato direto (WhatsApp ou telefone)
4. Se o fornecedor principal não atender, acionar o substituto

---

## Como Atualizar Este Arquivo

Sempre que houver mudança em fornecedor (novo parceiro, encerramento, mudança de preço ou contato):
1. Atualizar o registro correspondente
2. Registrar a mudança em `_memoria/decisoes-estrategicas.md` se for decisão estratégica
3. Fazer commit com mensagem: `fix(fornecedores): atualiza [nome do fornecedor] — [motivo]`

## 🎨 O Que Esta Skill Faz

### Direção Visual
- Define paleta de cores e seu uso
- Define tipografia (famílias, tamanhos, weights)
- Define espaçamento e ritmo visual
- Define hierarquia de elementos

### Orientação de Decisões
- Crítica de layouts e wireframes
- Validação de mobile-first
- Aprovação/rejeição visual antes de código

### Treinamento
- Educação em conversão visual em turismo
- Explicação de "por quê isso funciona"
- Referências a benchmark comprovado

### Componentes Padrão
- Hero block
- Card de passeio
- Seção de confiança (Cadastur + avaliação)
- CTA button
- Accordion/FAQ
- Footer

### Qualidade
- Checklist visual de 100+ items
- Validação antes de deploy
- Garantia de conversão

## 🎯 Princípios Defendidos

### Identidade Visual

A Vem Passear Jampa é visualmente:
- **Turístico Premium** — Alegre, leve, com energia
- **Alegre Local** — Celebra JP, não genérico
- **Confiável** — Sério nos detalhes
- **Claro** — Informação sem ruído
- **Humano** — Mostra Murillo, comunidade
- **Chamativo sem Bagunça** — Cores estratégicas

### Paleta (4 Cores)

| Cor | Uso | Sensação |
|-----|-----|----------|
| Azul Primária (#0066CC) | Backgrounds, headers, confiança | Segurança |
| Laranja Secundária (#FF6B35) | CTAs, destaque | Ação |
| Dark (#1a1a1a) | Backgrounds escuros | Profissional |
| Neutros | Espacos em branco | Clareza |

### Conversão Visual

- ✅ **Confiança acima da dobra** (Cadastur + avaliação)
- ✅ **Preço visível** (não "consulte")
- ✅ **CTA incômodo** (não ignorável)
- ✅ **Mobile-first** (70-80% turista usa)
- ✅ **Espaço branco** (não caos)
- ✅ **H1 claro** (responde pergunta do turista)

## ✅ Checklist de Aprovação (Rápido)

Antes de repassar layout para próxima etapa:

- [ ] H1 claro, responde pergunta turista?
- [ ] Prova social (Cadastur/avaliação) visível acima dobra?
- [ ] CTA em cor contraste, ≥44px?
- [ ] Mobile layout é 1 coluna stacked?
- [ ] Preço visível (não "consulte")?
- [ ] Espaço branco entre seções?
- [ ] Cores respeitam paleta (3-4 cores)?
- [ ] Tipografia é sans-serif, legível?
- [ ] Sem muita informação na dobra?
- [ ] Link WhatsApp funciona?

**Se todos SIM:** ✅ Aprovado  
**Se alguns NÃO:** ⚠️ Volta para refinamento

## 1. Propósito e Responsabilidade

A skill `radar-concorrentes-social` é a **autoridade em inteligência competitiva** para Instagram.

Ela existe para:
- 🔍 **Pesquisar concorrentes locais** (outros tours em JP)
- 📱 **Estudar referências visuais** (marcas que inspiram visualmente)
- 📊 **Analisar padrões de conteúdo** (o que funciona, o que não funciona)
- 📈 **Identificar gaps e oportunidades** (o que ninguém está fazendo)
- 💡 **Alimentar biblioteca de referências** (arquivo de ideias úteis)
- 🎯 **Validar diferencial da Vem Passear** (como somos melhores)
- 🔔 **Monitorar trends** (tendências que fazem sentido para JP)

### O Que Não Faz

❌ **Gerar pauta editorial** — responsabilidade de `social-media-editorial-turismo`  
❌ **Capturar imagens** — responsabilidade de `captura-referencias-visuais`  
❌ **Executar conteúdo** — implementação no Instagram  
❌ **Copiar direto dos concorrentes** — análise é para aprender princípios, não copiar  
❌ **Fazer benchmarks genéricos de turismo** — foco é turismo receptivo local

## 4. Tipos de Análise

### A. Análise de Concorrente Direto

```
CONCORRENTE: Jampa Paradise
URL: https://instagram.com/jampaparadise
Data da Análise: 2026-04-25

1. IDENTIDADE VISUAL
   ├─ Paleta: Azul + branco + verde água
   ├─ Tipografia: Sans-serif (aparenta ser)
   ├─ Tom: Formal, corporativo, professoral
   └─ O que Vem Passear faz MELHOR: Mais humano, menos corporativo

2. CADÊNCIA DE CONTEÚDO
   ├─ Stories: Diários (manhã + noite)
   ├─ Reels: 2-3 por semana
   ├─ Carrosséis: 1-2 por semana
   ├─ Posts estáticos: 2-3 por semana
   └─ OPORTUNIDADE: Vem Passear pode ser mais consistente em reels

3. TEMAS DE CONTEÚDO
   ├─ Passeios destaque (70% do conteúdo)
   ├─ Depoimentos (15%)
   ├─ Dicas de viajante (10%)
   ├─ Administrativo (5%)
   └─ GAPS: Não faz bastidor, não mostra Murillo, conteúdo é genérico

4. COPY STYLE
   ├─ Ton: Formal, educativo, sem personalidade
   ├─ CTA: "Saiba mais", "Consulte", genérico
   ├─ Emojis: Poucos
   └─ DIFERENCIAL: Vem Passear é MAIS humano, MAIS direto WhatsApp

5. ENGAJAMENTO (Estimado)
   ├─ Média likes: ~50-150 por post
   ├─ Comentários: Poucos (< 5)
   ├─ Shares: Raros
   └─ INSIGHT: Público não engaja tanto — oportunidade para Vem Passear se engajar mais

6. OPORTUNIDADES PARA VEM PASSEAR
   ✓ Ser mais humano (mostrar Murillo, bastidor)
   ✓ Copy mais acolhedor (não só informação técnica)
   ✓ Mais stories diários (top of mind)
   ✓ Mais conversação (perguntas, enquetes)
   ✓ Reels mais criativos (usar trends com bom senso)

7. O QUE COPIAR (Como Princípio)
   ✓ Cadência diária (stories + conteúdo estruturado)
   ✓ Mix de passeios + prova social + dicas
   ✓ Foto grande de destino em post estático
   ✓ Preço visível em anúncio de passeio

8. O QUE EVITAR
   ✗ Tom corporativo (Vem Passear é mais coloquial)
   ✗ Sem Murillo visível (pessoas compram de pessoas)
   ✗ Muita informação técnica sem humanidade
   ✗ CTA vago ("saiba mais") — deve ser WhatsApp direto
```

### B. Análise de Referência Visual

```
REFERÊNCIA: @brasildescobertas (Influenciador de viagem)
Interesse: Storytelling visual, como contar histórias de destino

PADRÕES OBSERVADOS
├─ Stories: Dia a dia da viagem (discovery)
├─ Reels: Moments curtos (3-10s), muito visuais, pouco texto
├─ Carrosséis: Guias (10-15 slides com informação prática)
├─ Posts estáticos: Foto grande + caption longa com história

CTA ANALYSIS
├─ Nunca vende direto (influenciador, não agência)
├─ Usa "venham comigo" (convida para experiência)
├─ Link em bio (para monetização)
└─ Não pede click — deixa conteúdo inspirar

VISUAL DIRECTION
├─ Cores: Quentes (sunset, golden hour, cores naturais)
├─ Tipografia: Hand-drawn + sans-serif (dinâmica)
├─ Emojis: Muitos, contextualizados 
├─ Layout: Muito white space (clean, não poluído)

APLICÁVEL À VEM PASSEAR?
✓ Storytelling: "Dia de passeio com cliente" = aplicar
✓ Golden hour: Usar pôr do sol como momento destaque
✓ Guia com 10-15 slides: Formato carrossel que Vem Passear pode usar
✓ "Venham comigo" tone: Fit com tom acolhedor

✗ Link em bio monetização: Não, CTA é WhatsApp
✗ Sem preço transparente: Vem Passear SEMPRE mostra preço

RECOMENDAÇÃO
Copiar estilo de storytelling (descoberta + experiência)
mas manter honestidade de preço e CTA claro
```

## 8. Guardrails e Limites

### Não Fazer

❌ **Copiar design/copy direto**
- Análise é para aprender PRINCÍPIOS
- Vem Passear cria próprio conteúdo

❌ **Obsessive monitoring**
- Pesquisa mensal/quinzenal é suficiente
- Não perseguir concorrente diariamente

❌ **Perder foco em turismo receptivo JP**
- Referências gerais ajudam, mas JP é foco
- Trends devem fazer sentido para público local

❌ **Ignorar diferencial Vem Passear**
- Não é "como ser como Jampa Paradise"
- É "como ser MELHOR que Jampa Paradise"

### Análises Obrigatórias

- [ ] Consultei vault antes de pesquisar?
- [ ] Identifiquei diferencial claro de Vem Passear?
- [ ] Princípios estão extraídos, não design copiado?
- [ ] Recomendações são práticas?
- [ ] Salvei em `_social/` com metadata?
